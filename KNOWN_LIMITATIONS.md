# Known Limitations

- default runtime paths still target Surwish OS on Miyoo Flip V2
- local desktop/dev setup still requires SDL2/PySDL2 and optional path overrides
- the UI is tuned for Miyoo Flip V2 screen layout
- markdown preview is intentionally simple, not a full renderer
- core flows were checked on real Miyoo Flip V2 hardware, but any future input or layout changes should still be revalidated on-device
