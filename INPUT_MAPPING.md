# Input Mapping

Default button scheme:

- `B`: confirm / select key
- `A`: shift in editor, note menu in list
- `Y`: backspace / delete
- `X`: space, create note in list
- `START`: settings in list, note menu in editor and preview
- `SELECT`: back, cancel, or quit from note list
- `L1`: previous layout
- `R1`: next layout
- `L2`: symbols layout toggle
- `R2`: enter / confirm dialog
- d-pad: move selection
- left stick: move selection
- right stick up/down: move text cursor one line
- right stick left/right: move text cursor one character

Swapped button scheme:

- swaps `A` and `B` for confirm and shift behavior
- `Y` and `X` stay the same
